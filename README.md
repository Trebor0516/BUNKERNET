# **BUNKERNET**

Sistema de chat colaborativo en tiempo real utilizando WebSocket.

## **Descripcion**

Aplicacion web que permite la comunicacion real entre multiples usuarios mediante WebSocket.

El sistema permite:
  - Envio y recepcion de mensajes en tiempo real.
  - Historial visible de mensajes.
  - Conexion simultanea de multiples usuarios.
  - Notificacion de usuarios conectados y desconectados
  - Asignacion automatica de nombres temporales.

## **Requisitos**
Para ejecutar el proyecto se requiere:
  - Node.js v18 o superior.
  - Conexion a internet.

## **Manual de instalacion,ejecucion**
  1. Clonar repositorio
  - git clone https://github.com/Trebor0516/BUNKERNET
  2. Ingresar a la carpeta
  - cd BUNKERNET
  3. Instalar dependencias
  - npm install express ws
  - npm install sqlite3
  4. Ejecutar servidor
  - node server.js
  5. Abrir cliente 
  - Ingresar a: http://localhost:3000
  6. Abrir:
  -https://bunkernet.onrender.com
